WINDOWS UPDATE:
  1. Stop the old terminal with Ctrl+C.
  2. Extract the v1.1.2 hotfix over the existing stepahead-lab folder.
     Keep data/, .git/, .venv/ (they are not in the archive).
  3. Run start.bat; ensure tests pass.
  4. Run publish-to-github.bat; confirm it says PUBLISHED.
     Git pager is disabled; local master is renamed to main if necessary.

MAC NEW INSTALL (after Windows push succeeds):
  1. Open Terminal.
  2. mkdir -p ~/Documents && cd ~/Documents
  3. git clone https://github.com/Wandersport/WS-StepAhead-Lab.git
  4. cd WS-StepAhead-Lab
  5. bash start.command

MAC LATER UPDATES (stop monitor first):
  cd ~/Documents/WS-StepAhead-Lab
  git pull --ff-only
  bash start.command

supported python3.14/3.13/3.12/3.11/3 interpreter available.
